# Kode forklarelse
Først printer den en meny så bruker kan se hvilke valg de har.
så har jeg brukt if/elif/else for å velge mellom de forskjelige som setter forskjelig verdi på pris.
if/elif/else er inni funksjoner for at koden ikke skal fortsete etter det er et invalid input.
så til slutt printer den prisen på det brukeren bestilte.

# Legge til mere
For å legge til mere er det bare å skrive det inn på toppen så det står i menyen også legge det in som en nye elif med pris.
